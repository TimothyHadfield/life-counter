# Existing tools (checked 2026-10-15)

Quick search before building. Nothing free does all of: friends list + benchmarks + calendar export, with no tracking.

| Tool | Free? | Good | Missing | Money |
|---|---|---|---|---|
| [AgeSphere (iOS)](https://apps.apple.com/app/id6754945692) | 3 people free | 1B / 2B seconds, day milestones | Friends capped at 3, no calendar export | $3.99 one-time |
| [Age Calculator & Event Tracker (iOS)](https://apps.apple.com/us/app/-/id6444581024) | Yes, with ads | Friends sharing, reminders | Ads, tracking | Ads |
| [Age Calculator Birth Track (iOS)](https://apps.apple.com/us/app/-/id1572181494) | Partly | 10,000th day, golden birthday, family profiles | No calendar export | In-app |
| [itoolverse age calculator (web)](https://www.itoolverse.com/calculator/age-calculator) | Yes | Live seconds counter | One person, no milestones list | Ads |
| "10,000 day" calculator pages | Yes | One milestone date | No .ics, low-quality pages | Ads |

Verdict: build it. Small app, the date math is simple, and no existing tool exports milestones to a calendar.
