# Life Counter

How old you and your friends are in every unit (live, down to the second), the dates you hit benchmarks like 1 billion seconds or 10,000 days, odd birth facts, and friend comparisons. Milestones export as one calendar file (Apple Calendar or Google Calendar import). Birthdays stay in your browser; nothing is sent anywhere.

- Live: https://timothyhadfield.github.io/life-counter/
- Run locally: open `LifeCounter.html`, or `python -m http.server` in this folder.
- Tests: `node tests/lifecalc.test.js`
